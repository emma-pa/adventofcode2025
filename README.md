My solutions to some puzzles of [Advent Of Code 2025](https://adventofcode.com/) using Python.

## How to run it

### Install dependencies

You'll need [uv](https://docs.astral.sh/uv/getting-started/installation/). Then, run:

```shell
uv sync
```

### Run puzzles

For example with day 1:

```shell
uv run python -m puzzles.day1
```

### Run tests

For example with day 1:

```shell
uv run python -m unittest puzzles.day1.tests
```
